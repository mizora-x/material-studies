THE SWITCH
- 成形されたベゼル内のピル形状のスイッチ：冬は霜のついたアルミ（霜のきらめき粒）、春はクリーム色のエナメル。柔らかいドロップシャドウがページに落ち、キャンバスエッジ前に消え、トラックのトップに沿ってわずかな内側シャドウ。
- 内部に176×50ピクセルアートの山あいの窪地、CPU上で毎フレーム再描画（冬の世界と春の世界の2枚）、ニアレストサンプリングで表示、決してスムーズにしない。シーンピクセルあたり整数個のデバイスピクセルを可能な限り使用。
- ノブは透明な雫ガラスの垂直カプセル、トラックより少し高く、1つのフルキャンバスWebGL2フラグメントシェーダーで描画：
  - 下のピクセルを拡大（~1.28×）し、曲げる；
  - リムでR/G/Bを分割、より暗い屈折バンド、明るいエッジ、フレネルティント；
  - 2つのハイライト：左上部の長い柔らかいストリークと右下部の小さなドット；
  - 足元に向かって光を集中させ、シーンに柔らかいシャドウ；
  - まだ冬を向いている右側のリムに霜（ノイズ）、春が進むと消える。
- ノブはスプリングで指に遅れ、速度に応じて水平に伸び（体積を保つために垂直に圧縮）、加速度で供給される減衰スプリングで揺れる。
- ノブ内部は常に春の世界：ガラスが春を運ぶ。雪だるまの融解や桜の開花は、まずガラスの下で始まる。
- コントロール：ノブをドラッグするかトラック上のどこかをドラッグ；タップで反対端にトグル；矢印キー、Home/End、Space/Enter；role="slider" に aria 値。

THE HOLLOW (original, storybook palette)
塗りつぶし形状から自動1-pxアウトラインと明るい上部/暗い下部でスタンプ。すべて冬版と春版を持つ：
- ディザのかかった空、2層の山並み（遠景は雪山→春は頂だけ雪）、小さな松の並ぶ丘、雪原→草地、戸口からの小道；
- 左に大きな松（雪を載せる）、丸太小屋（雪屋根とつらら→赤い板葺き、煙突の煙、窓、壁の温度計）；
- 切り株の上の真鍮ホーンの蓄音機；
- 帽子とマフラーの雪だるま；
- 中央手前の池（ひびの入る氷→さざ波、流氷、睡蓮、カエル）；
- 熊の巣穴のある小山（雪の塚→花の咲く草の丘）；
- 桜の木（雪の載った裸枝→つぼみ→満開）；
- 右端の石灯籠；
- 上辺を横切るたるんだロープに12個の提灯、冬はそれぞれにつららが下がる。

THAW AND THE SPRING
- ノブが窪地を横切って春をドラッグ：左側は春、右側はまだ冬。エッジは4×4 Bayerディザで溶け、ノブのすぐ後ろに雪解け水のきらめきバンド。
- 冬の空は濃紺の薄暮に星と揺れるオーロラ、降る雪；春の空は藤色と桃色の霞から青空へ、山の向こうから昇る太陽、流れる雲、斜めの陽光。
- ストーブは早く点き、窓から雪の上にバンド状の暖かいプールを投げる。
- 各提灯はノブが通過するとつららが落ちて点き（最後の一滴が落ちる）、色付きディザ光。
- 雪だるまは融けて帽子とニンジンと水たまりに；草地には通過後に花が順に芽吹く。
- 祭りでは空に虹、花びらが舞い、提灯が拍に合わせて明滅。
- 壁の温度計は−12°Cから+18°Cまで。

THE STORY, BY POSITION
- 茶色の子熊：
  - 巣穴で丸まって眠り、呼吸し、zが上がる；
  - 目覚めて穴から顔を出し、まばたき、ときどきあくび；
  - 巣穴の前に座って体をかく；
  - 立ち上がって桜の木の下まで歩く；
  - 最後は後ろ足でビートに合わせてダンス、花冠をかぶりピンクのゴーストトレイル。
- 蓄音機のホーンがビートでふくらみ、音符が浮かぶ；蝶が飛ぶ；カエルが拍で跳ねる。
- 移動するノブの後ろに光る三日月エコー（ミントからピンク）がトレイル。
- 終わり近く（約+12°Cから）雁の群れが右上の空を旋回して待つ：約2.8 sごとに3回鳴き、鳴くたびに群れが2 px跳ね、音の弧が飛び、熊の上に「！」がポップ。最後は群れが池に降り、白い親鳥と黄色いひな3羽が泳いで入り、ビートに合わせてボブ。

SOUND — all synthesised live with Web Audio, original music
- 96 BPM、D（Dmaj7 · Bm7 · Gmaj7 · A7sus4）の4小節ループ、わずかなスウィングの1つのlookaheadスケジュール時計。
- レイヤーはノブの位置でフェードイン：
  0. 冬：うなる風（LFOで掃引するバンドパスノイズ）とまばらな氷のチャイム。
  1. コードをアルペジオするカリンバ（サイン＋短い金属パーシャルとクリック、短いリバーブ）。
  2. ブラシ風ローファイビート（キック、リム、シェイカー）と丸いベース。
  3. 暖かいデチューンパッドとビブラートの口笛チューン（サイン＋息のノイズ）、春の鳥のさえずり。
  4. 祭り：4つ打ち、クラップ、タンバリン、サブベース、キックの下でミックスがポンピング。
- 音楽は雪解けで開くローパスの後ろに、~5 dBでスイッチ自身の音の下。
- スイッチ音：
  - つかむと氷のチンとブロップ、離すとプロップ；
  - ドラッグ速度に追従するバンドパスノイズの擦れ；
  - 落ちるつららごとにペンタトニックの滴（掃くとグリッサンド）、凍り直すと柔らかく低く；
  - ストーブの掛け金のダブルクリックと目覚めの熊のあくび（フォルマントフィルタードソー）；
  - 池の氷が割れる音（2回）、雪だるまの帽子が落ちるスライドホイッスル；
  - 祭りへのライザーとクラッシュ、祭りからドラッグバックのレコードブレーキ；
  - 雁が着水するときのスプラッシュとクワッ。
- 雁の声：0.27 s間隔の3声、群れの方向へパン。各声は300→410→330 Hzの鼻にかかったソー波を2つのフォルマント（~780 / ~1550 Hz）に通し、速いAMと柔らかいサチュレーション。音楽は各声で~45%にダック。
- オーディオは最初のタッチで開始；Sound on/offボタン。
- 表示：Temp (−12°C〜+18°C), Season (Deep winter / First drip / Thaw / Spring / Festival), Music (Wind / Kalimba / Beat / Band / Festival)。
