「Daybreak Switch」を作成してください。ウェブ素材研究シリーズのNo. 062：独自のオリジナルスタイルによる夜から朝へのトグルを、単一の自己完結型ページとして（ライブラリなし；生のWebGL2 + Web Audio + 2Dピクセルバッファ）。編集レイアウト：小さな「Material Studies / No. 062 · WebGL + Web Audio」キッカー、斜体セリフタイトル「Daybreak Switch.」、1行のキャプション；スイッチを中央に大きく配置；その下に表示（Clock, Light, Music）、ヒント行と「Sound on/off」ボタン。ページ全体の色（背景、テキスト、線）は、スイッチに従って夜の暗い黄昏インディゴから昼の淡いラベンダーグレーへ変化。電話幅で動作。

THE SWITCH
- 成形されたベゼル内のピル形状のスイッチ：昼は白い光沢プラスチック、夜はグラファイト。柔らかいドロップシャドウがページに落ち、キャンバスエッジ前に消え、トラックのトップに沿ってわずかな内側シャドウ。
- 内部に176×50ピクセルアートの部屋、CPU上で毎フレーム再描画され、ニアレストサンプリングで表示、決してスムーズにしない。シーンごとのデバイスピクセルを可能な限り使用。
- ノブは透明なジェリーガラスの垂直カプセル、トラックより少し高く、1つのフルキャンバスWebGL2フラグメントシェーダーで描画：
  - 下のピクセルを拡大（~1.28×）し、曲げる；
  - リムでR/G/Bを分割、より暗い屈折バンド、明るいエッジ、フレネルティント；
  - 2つのハイライト：左上部の長い柔らかいストリークと右下部の小さなドット；
  - 足元に向かって光を集中させ、部屋に柔らかいシャドウ。
- ノブはスプリングで指に遅れ、速度に応じて水平に伸び（体積を保つために垂直に圧縮）、加速度で供給される減衰スプリングで揺れる。
- ノブ内部の部屋は常に完全に照明：ガラスが朝を運ぶ。
- コントロール：ノブをドラッグするかトラック上のどこかをドラッグ；タップで反対端にトグル（スプリングでそこへ移動）；矢印キー、Home/End、Space/Enter；role="slider" に aria 値。

THE ROOM (original, cosy palette)
塗りつぶし形状から自動1-pxアウトラインと明るい上部/暗い下部でスタンプされ、すべてのオブジェクトがピクセルスプライトとして読めるように構築：
- バターイエローのダイヤモンド壁紙、ティール腰壁、板張り床、コーラル/クリーム/ティールのストライプラグ；
- 屋根の町の上にカーテンの大きな窓；
- 色付きジェリー瓶と本の棚、鉢植えの植物；
- ミントシェードの真鍮フロアランプ；
- 木製キャビネット上の赤いブームボックス、額縁の小さなジェリーシャークの絵、丸い壁時計、青いパネルドア；
- 天井を横切るたるんだ色付き電球の列；
- 窓下のパープルペットベッド。

LIGHT AND THE MORNING
- ノブが部屋を横切って夜明けをドラッグ：左側は昼、右側はまだ夜（インディゴアンビエント）。エッジは4×4 Bayerジザーで溶け、ノブのすぐ後ろに暖かい夜明けバンド。
- 窓の空は夜（ネイビー、きらめく星、三日月、灯る町の窓）から夜明け（バイオレットからピーチ、昇る太陽）へ、昼（ブルー、高い太陽、漂う雲）へ。
- 夜は月光が窓からシャフト、昼は暖かい陽光シャフト。
- ランプは早く点き、バンド状の暖かいプールを投げる。
- 各天井電球はノブが通過すると点き、色付きジザー光。
- パーティーでディスコスポットが部屋を掃く。
- 壁時計は02:00から10:00まで。

THE STORY, BY POSITION
- オレンジのタビー猫：
  - ベッドで丸まって眠り、呼吸し、zが上がる；
  - 目覚めて頭を上げて横たわり、まばたき；
  - 座る；
  - 立ち上がってラグの上を歩く；
  - 最後は後ろ足でビートに合わせてダンス、サングラスでピンクのゴーストトレイル。
- 植物が揺れ、ブームボックスのスピーカーがビートでドンドン；音楽ノートがブームボックスから浮かぶ。
- ディスコボールが天井から降り、コンフェッティのきらめきが落ちる。
- 移動するノブの後ろに光る三日月エコー（コーラルからピンク）がトレイル。
- 終わり近く（時計で約08:24から）子犬が外で待つ：暖かい光がドア下に、シフトする足の影で、ノック。ノックごとにドアが2 px揺れ、音の弧が飛び、猫の上に「！」がポップ；ノックは入るまで約2.8 sごとに繰り返す。最後はドアが暖かいオレンジの廊下に開き、茶色の耳の白い子犬が入り、ビートに合わせてボブ。

SOUND — all synthesised live with Web Audio, original music
- 100 BPM、F（Fmaj7 · Am7 · Dm7 · B♭maj7）の4小節ループ、わずかなスウィングの1つのlookaheadスケジュール時計。
- レイヤーはノブの位置でフェードイン：
  0. 夜：コオロギ（AM-チルプしたサイン列）と柔らかい風。
  1. コードをアルペジオする音楽箱（ベルパーシャル、短い部屋リバーブ）。
  2. ローファイビート（キック、ノイズとトーンスネア、ハット）と丸いベース。
  3. 暖かいデチューンパッドとビブラートのスクエアウェーブチューン。
  4. パーティー：4つ打ち、クラップ、オープンハット、サブベース、キックの下でミックスがポンピング。
- 音楽は夜明けで開くローパスの後ろに、~5 dBでスイッチ自身の音の下。
- スイッチ音：
  - つかむとガラスのチンとジェリーブロップ、離すとプロップ；
  - ドラッグ速度に追従するバンドパスノイズの擦れ；
  - 点く電球ごとにペンタトニックスプラック（掃くとグリッサンド）、消えると柔らかく低く；
  - ランプのダブルクリックと目覚めの猫の「mrrp」（フォルマントフィルタードソー）；
  - パーティーへのライザーとクラッシュ、ビートからドラッグバックのレコードブレーキ；
  - 子犬が入るときのyip。
- ノックは本物の重いドアノックのように：0.25 s間隔の3ヒット、ドアに向かってパン。各ヒットは深いサグ（~98から~60 Hz、1/4秒で）上のノックルクリック（バンドパスノイズ）、速い倍音（190→128 Hz、410 Hz）と柔らかいサチュレーションで小さなスピーカーでも聞こえる。音楽は各ヒットで~45%にダック、ノックは音楽の3–4×でピーク。
- オーディオは最初のタッチで開始；Sound on/offボタン。
- 表示：Clock (02:00–10:00), Light (Night / First light / Sunrise / Morning / Party), Music (Crickets / Music box / Beat / Band / Party)。
